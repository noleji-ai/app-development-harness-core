# Source baseline and public repository history

This snapshot derives from App Development Harness 1.2.0, source revision `1e391c52b96a52024c71dd447ad7b3c1b54ee53f`. The first public commit records this snapshot, not the original start of development. Private history and previous private release archives are excluded.

## Included source and notices

TypeScript source, tests, plugin contracts, dashboard implementation, dependency lock and MIT notice are retained. Node bundles include the Zod notice; personal build-location comments are removed. Korean/English entry guides and a Python evidence checker accompany the baseline.

## Excluded material and verification limits

Two generated concept images, credentials, customer/student data and private account configuration are excluded. Existing dashboard tokens remain documented without publishing reference artwork. The Python tool checks consistency and hashes, not identity or grant eligibility. [Verification](docs/verification.md) separates local checks from unverified external use and program selection.
