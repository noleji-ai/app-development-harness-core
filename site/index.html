git clone https://github.com/noleji-ai/app-development-harness-core.git
cd app-development-harness-core
node dist/cli.js --help
DEMO_PROJECT=$(mktemp -d)
node dist/cli.js init --project "$DEMO_PROJECT" --mode create
node dist/cli.js status --project "$DEMO_PROJECT"
node dist/cli.js doctor --project "$DEMO_PROJECT"

BEFORE YOU START

시작 전에 확인할 내용

브라우저에서 앱 개발을 실행하나요?

이 페이지는 상태 변화를 설명하는 예시입니다. 실제 도구는 공개 저장소의 소스를 내려받아 로컬에서 실행합니다.

모델 호출 없이 확인할 수 있나요?

초기화·상태·진단 예제는 모델을 호출하지 않습니다. 실제 개발 실행의 계정과 비용은 별도로 확인해야 합니다.

다른 개발 도구와 어떻게 다른가요?

개발 절차와 실행 기록을 연결하는 작은 코어입니다. 기존 도구를 대체하거나 더 우수하다고 검증한 것은 아닙니다.

무료로 사용할 수 있나요?

코드는 MIT로 공개합니다. 직접 사용하는 모델 계정, 제공자 호출 비용과 호스팅은 별도입니다. OpenAI와 독립적으로 운영하며 공식 추천이나 무료 사용량을 보장하지 않습니다.
